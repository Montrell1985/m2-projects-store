# M2 Projects LLC Store

M2 Projects LLC is planning a digital storefront for real estate wholesalers and small investors. The store will sell one-time downloads of Excel workbooks for analyzing property deals and managing leads.

The initial page introduces the Deal Analyzer Workbook ($29) and Lead Tracker Workbook ($19). Open `index.html` in a browser to view it. The course demo will use simulated payments and sample downloads.

## Planned shopping flow

Store Homepage → Catalog → Product Details → Cart → Checkout → Order Confirmation and Download

Help will cover file compatibility and download support.
